# Framio CLI

Official Command-Line Interface for [Framio](https://github.com/FramioApp).

[![npm version](https://img.shields.io/npm/v/framio.svg)](https://www.npmjs.com/package/framio)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## Installation

You can run `framio` directly using `npx`:

```bash
npx framio
```

Or install it globally via `npm`:

```bash
npm install -g framio
```

## Usage

```bash
# Run default command
framio

# Greet a specific user
framio hello "Alice"

# Display version
framio --version

# Display help
framio --help
```

## Options & Flags

| Option | Shorthand | Description |
| --- | --- | --- |
| `--help` | `-h` | Show help and available commands |
| `--version` | `-v` | Display the installed version |
